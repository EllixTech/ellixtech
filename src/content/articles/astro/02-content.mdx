## Add MDX support

MDX combines Markdown writing with reusable components. Install Astro's official integration, then create a directory for your articles.

```sh
pnpm astro add mdx
```

## Define the collection

Use a content loader and a schema to catch missing or malformed metadata at build time.

```ts
import { defineCollection, z } from 'astro:content';
import { glob } from 'astro/loaders';

const articles = defineCollection({
  loader: glob({
    pattern: '**/*.mdx',
    base: './src/content/articles'
  }),
  schema: z.object({
    title: z.string(),
    date: z.coerce.date()
  })
});

export const collections = { articles };
```

Save this in `src/content.config.ts`. Add a description and language field as your publication grows.

## Render the article

A dynamic route can use `getStaticPaths` to enumerate entries and `render` to turn an entry into its content component. The result remains a static page.

Keep presentation in your layout and editorial content in MDX. This makes a design change independent of the writing.

## Verify your content

Run a production build after adding an article. The schema should reject missing required fields, while the generated page should show its title, date, headings, and code blocks.
