## ¿Qué necesita quien lee?

En una publicación técnica, el contenido debe llegar pronto y mantenerse legible. Un buen punto de partida es separar el documento de las interacciones que lo acompañan.

El texto, los enlaces y la estructura de la página pueden existir sin esperar a que se ejecute JavaScript.

## Añade comportamiento con intención

Un buscador necesita responder a lo que escribe la persona. Un bloque de texto no necesita una aplicación completa para aparecer en pantalla.

Esta diferencia permite elegir límites pequeños para la interactividad y conservar una base sencilla.

## Comprueba la experiencia real

Prueba la página con una pantalla estrecha, navega con el teclado y cambia el tamaño del texto. Observa si el contenido mantiene su orden y si los controles tienen nombres comprensibles.

La calidad de una web también está en estas decisiones pequeñas. El objetivo no es eliminar herramientas: es utilizarlas para resolver una necesidad concreta.
